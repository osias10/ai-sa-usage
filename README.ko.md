# AI SA

**AI 구독 사용량을 바탕화면에서 바로 확인하세요.**

[English](README.md) · **한국어**

AI SA는 AI 구독 한도를 한눈에 확인할 수 있는 작은 Windows 위젯입니다. 사용량 페이지를 매번 열지 않아도 얼마나 사용했는지, 언제 초기화되는지, 확인이 필요한 계정은 무엇인지 볼 수 있습니다.

Windows 11 x64 · 바탕화면 위젯 & 시스템 트레이 · 0.4.11 (정식)

**사용량 통계와 절전 복귀 후 빈 여백 수정을 포함한 정식 버전:** [0.4.11 다운로드](https://github.com/osias10/ai-sa-usage/releases/tag/v0.4.11), 또는 **설정 → 정보**에서 업데이트를 확인하세요. 0.4.11-beta.5까지의 변경 사항을 포함하며, 프리릴리스 업데이트 옵션을 꺼도 받을 수 있습니다.

## 한눈에 보는 기능

- **사용량과 초기화 시간.** 사용률, 게이지, 초기화까지 남은 시간을 표시합니다. 사용량과 잔여량 중 원하는 방식으로 볼 수 있습니다.
- **원하는 항목만 선택.** 계정마다 여러 한도를 표시할 수 있습니다. Claude는 세션·주간 전체와 함께, 서비스에서 제공하는 Fable 등의 한도도 선택할 수 있습니다.
- **트레이는 별도로.** 위젯에는 세션·주간을 띄우고, 트레이 숫자는 Fable이나 다른 한도로 지정할 수 있습니다.
- **원하는 주기로 갱신.** 계정별·전체 수동 새로고침을 지원하며, 자동 갱신은 1분부터 24시간까지 설정할 수 있습니다.
- **원하는 사용률에서 알림.** 한도별로 알림을 켜고, 알림을 받을 사용률을 직접 정할 수 있습니다.
- **초기화 알림.** 설정 → 계정 → 계정 설정의 **한도별 알림**에서 원하는 한도의 초기화 알림을 켜세요. 새 조회에서 초기화가 확인되면 한 번 알려줍니다. 기본값은 꺼짐이며, 사용률 알림과 따로 설정할 수 있습니다.
- **초기화 후 자동 메시지.** Claude·Codex의 계정 설정에서 **세션 초기화 후 자동 메시지**를 켜면 세션 초기화 후 짧은 메시지를 보냅니다. 계정별 기본 꺼짐이며, 구독 사용량이 소모되고 앱이 실행 중일 때 동작합니다. 전송 전 계정과 한도를 확인하고 결과가 불명확하면 앱에서 재전송하지 않습니다. 실제 구독 계정에서의 전송은 아직 검증하지 않았습니다.
- **소진 시각 예상.** 설정 → 위젯에서 **소진 예상**을 켜면 최근 사용 추이로 한도 소진까지 남은 시간을 예상합니다. **위젯에 예상 표시**는 별도로 끌 수 있으며, 계정 화면에서도 결과를 확인할 수 있습니다. 기능은 기본 꺼짐입니다.
- **사용량 통계 저장.** 설정 → 위젯에서 켜면 정상 갱신마다 기록합니다. 저장·소진 예상·위젯 표시는 각각 선택할 수 있고, 저장을 꺼도 기존 기록은 보관합니다. **기록 삭제**로 직접 비울 수 있습니다.
- **모아 둔 사용량 보기.** **설정 → 통계**에서 계정·한도와 최근 1·6·24시간을 선택하세요. 추이 그래프, 마지막·최고 사용률, 확인된 증가량(%p), 개별 조회 기록을 볼 수 있습니다. 그래프에 마우스를 올리거나 방향키로 기록을 확인합니다.
- **내 바탕화면에 맞게.** 크기와 위젯 전체 투명도를 조절하고, 밝은 테마·어두운 테마·항상 위·위치 잠금을 설정할 수 있습니다.
- **위젯 표시 선택.** **설정 → 위젯 → 위젯 표시**에서 창을 켜거나 숨길 수 있습니다. 재시작 후에도 선택을 기억하며, 숨겨도 사용량 갱신과 트레이는 계속 동작합니다.
- **모니터 위치 기억.** 모니터를 다시 연결하거나 화면 배치·배율을 바꿔도 위젯을 놓았던 위치를 기억합니다.
- **클릭 통과.** 사용량을 띄워 둔 채 위젯 아래의 앱을 조작할 수 있습니다. 설정·트레이 메뉴·**Ctrl+Alt+W**로 켜고 끕니다.

소진 예상은 저장된 통계에서 최소 10분간 3회 이상 조회하고 사용량 증가가 확인된 뒤 표시됩니다. 현재 속도가 이어진다는 가정이며, 초기화가 먼저 오거나 데이터가 부족하면 그 상태를 표시합니다. 통계는 PC에만 최대 24시간 보관합니다. 저장을 끄면 새 기록만 멈추고, 소진 예상을 끄면 계산만 멈춥니다.

위젯은 Alt+Tab과 작업표시줄에 나타나지 않습니다. 처음 열릴 때 저장한 너비와 위치를 유지하면서 내용에 맞게 높이를 맞춥니다. 0.4.11에서는 계정이 3개 이상일 때 크기 맞춤 후 불필요한 스크롤이 생기던 문제도 수정했습니다. 내용이 화면의 사용 가능한 높이를 넘을 때는 스크롤을 유지합니다. 설정은 별도 창으로 열리며, 자동 시작을 켜면 Windows 로그인과 함께 실행됩니다.

위젯을 이동한 뒤 절전 복귀 중 모니터가 잠시 사라지면 창 높이가 불필요하게 커지던 문제도 수정했습니다. 오류 안내가 사라진 뒤 남던 여백과 창 복원 도중 화면 배율 변경 알림 처리도 개선했습니다.

## 서비스별 제공 범위

| 서비스 | 확인할 수 있는 항목 | 계정 |
| --- | --- | --- |
| **Claude** | 세션·주간 전체, 서비스가 제공하는 Fable 등의 추가 한도 | 여러 계정 |
| **Codex** | ChatGPT 구독에 포함된 Codex 한도 | 여러 계정 |
| **Antigravity** | 공식 도구에서 제공하는 모델별 한도 | 현재 로그인한 계정 |
| **Gemini 웹** | 공식 사이트 바로가기. 사용량 자동 조회는 제공하지 않습니다. | — |

AI SA는 **구독 한도**를 표시합니다. API 과금이나 토큰 비용을 집계하는 앱은 아니며, Antigravity 사용량과 Gemini 웹 사용량은 서로 다릅니다.

현재 초기 개발 단계입니다. Claude는 연결된 Max 계정으로 확인했으며, Codex와 Antigravity 연동은 실제 구독 계정에서의 검증이 더 필요합니다.

## 시작하기

**Windows 11 x64 PC가 필요합니다.** 앱은 현재 한국어 UI를 제공합니다. [최신 공개 버전 다운로드](https://github.com/osias10/ai-sa-usage/releases/latest)

1. 릴리스의 첨부 파일에서 `AISA-{버전}-win-x64-setup.exe`를 내려받아 실행합니다. 관리자 권한 없이 현재 사용자 계정에 설치됩니다.
2. **설정 → 계정 → 계정 추가**에서 서비스를 선택합니다.
3. 공급자의 로그인 절차를 완료합니다. 필요한 공식 도구는 AI SA가 자동으로 준비하므로, API 키나 터미널 명령 입력, 별도 개발 도구 설치가 필요하지 않습니다.
4. **계정 설정 → 위젯 표시 항목**에서 원하는 한도를 고릅니다. 트레이에 표시할 계정과 한도는 **위젯** 탭에서 따로 선택합니다.

처음 연결할 때는 인터넷 연결이 필요하며, 서비스별로 수백 MB의 도구를 내려받을 수 있습니다.

## 자주 쓰는 조작

| 하고 싶은 일 | 방법 |
| --- | --- |
| 설정 열기 | 위젯을 두 번 클릭하거나 트레이 메뉴 이용 |
| 사용량 새로고침 | 위젯을 선택한 상태에서 **F5**, 또는 마우스 오른쪽 버튼 메뉴 |
| 투명도 조절 | **설정 → 위젯 → 위젯 투명도**. 글자·아이콘·게이지·배경에 함께 적용 |
| 클릭 통과 전환 | **설정 → 위젯 → 클릭 통과**, 트레이의 **클릭 통과** 체크 항목, 또는 다른 앱에서도 **Ctrl+Alt+W** |
| 트레이 숫자 선택 | **설정 → 위젯 → 트레이 표시 계정 / 트레이 표시 항목** |
| 마지막 확인 시간 표시 | **설정 → 위젯 → 마지막 확인 시간** |
| 위젯 표시·숨기기 | **설정 → 위젯 → 위젯 표시** 또는 트레이 메뉴. 재시작 후에도 유지 |
| 숨긴 위젯 다시 열기 | 트레이 메뉴의 **위젯 열기** |
| 앱 종료 | 트레이 메뉴의 **종료** |

변경한 설정은 자동 저장됩니다. 투명도를 100%로 설정하면 위젯 전체가 보이지 않지만, 트레이 메뉴와 설정 창에서 언제든 다시 조절할 수 있습니다.

클릭 통과는 기본 꺼짐이며 재시작 후에도 선택을 유지합니다. 켜면 위젯 전체의 마우스 입력이 아래 창으로 전달되어 이동·크기 조절·두 번 클릭·오른쪽 버튼 메뉴를 사용할 수 없습니다. 위젯을 조작하려면 트레이나 **Ctrl+Alt+W**로 끄세요. 다른 앱이 단축키를 사용 중이면 트레이 메뉴를 이용할 수 있습니다. 설정 창과 트레이는 계속 조작할 수 있고, 투명도·위치 잠금은 별도로 유지됩니다.

모니터와 화면 안의 상대 위치를 기억하고 배율 변경을 반영합니다. 모니터 연결이 끊기면 사용 가능한 화면에 임시로 표시하며, 다시 연결하면 원래 위치로 돌아갑니다. 직접 이동하거나 크기를 바꾸면 그 위치를 새 기준으로 기억합니다. 별도로 켤 설정은 없으며 위치 잠금은 독립적으로 유지됩니다.

## 업데이트

**0.4.6부터** GitHub의 새 정식 버전을 24시간마다 확인하고, 버전별로 한 번 알립니다. **설정 → 정보**에서 자동 확인을 끄거나 직접 확인할 수 있습니다. 트레이의 **업데이트** 메뉴에서도 같은 화면을 엽니다.

**다운로드**를 누르면 설치 파일을 내려받아 검증합니다. 다운로드를 취소하거나 위젯을 계속 사용할 수 있습니다. 완료 후 **설치 실행**을 누르면 설정을 저장하고 설치 마법사를 연 뒤 앱이 종료됩니다. 설치를 마치고 **AI SA 실행**을 선택하면 다시 열립니다. 기존 계정과 위젯 설정은 유지됩니다.

**0.4.10부터** 설정 → 정보에서 **프리릴리스 업데이트 받기**를 켤 수 있습니다. 기본값은 꺼짐이며 자동 확인과 별도로 설정합니다. 켜면 정식과 프리릴리스 중 더 최신 버전을 안내하고, 버전 옆에 배포 구분을 표시합니다.

프리릴리스를 사용하다 옵션을 끄면, 버전 번호가 더 낮아도 최신 정식으로 돌아갈 수 있습니다. **정식 버전 다운로드 → 정식 버전 설치**를 눌러 기존 설치 마법사를 진행하세요. 옵션을 끄기만 하면 앱을 종료하거나 설치하지 않습니다. 다운로드 중 옵션을 바꾸면 기존 다운로드를 취소하고 새 선택에 맞춰 다시 확인합니다.

계정·위젯 위치·자동 시작·사용량 통계는 유지됩니다. 프리릴리스 전환 직전에 앱 설정과 데이터를 백업하며 로그인 인증 파일은 복사하지 않습니다. 로컬 백업은 생성 후 24시간이 지나면 다음 앱 실행이나 버전 전환 시 정리하고, **기록 삭제**는 백업된 통계도 지웁니다. 프리릴리스는 최신 정식 버전과 저장 형식이 호환되는 경우에만 배포합니다.

**0.4.5 사용자는 최신 정식 버전을 처음 한 번 직접 설치해야 합니다.** 기존 버전에는 업데이트 주소가 등록되지 않았습니다. 0.4.10 미만에서는 정식만 조회하므로, 먼저 최신 정식으로 업데이트한 뒤 프리릴리스를 선택하세요.

## 상태는 명확하게, 설정은 내 기기에

새로고침 아이콘은 조회가 진행 중이라는 뜻입니다. 조회가 끝난 뒤 문제가 있으면 느낌표가 표시됩니다. 갱신에 실패하면 마지막 정상값과 확인 시각을 유지합니다. 제공되지 않는 한도는 `—`로 표시하며, 초기화 시간이 지났다고 사용량을 임의로 0%로 바꾸지 않습니다.

AI SA는 자체 서버 없이 PC에서 동작합니다. 설정과 조회한 사용량 데이터는 기기에 저장하고, 로그인과 사용량 조회는 공급자의 공식 도구와 서비스를 이용합니다. 사용량을 확인하기 위해 질문을 보내거나 모델 생성 작업을 실행하지 않습니다. 별도 옵션인 초기화 후 자동 메시지를 켜면 짧은 질문을 보내며 구독 사용량을 소모합니다.

빌드 방법, 연동 세부 사항, 검증 기록은 [개발 문서](DEVELOPMENT.md)에서 확인할 수 있습니다.
